ZTask · 团队事项跟踪 原型总览

本地服务 + Web UI + 本地存储的单机工具（架构形态参考 DeepSeek Harness）；通过局域网分享「成员链接」，让每位成员查看团队全部事项，但只能更新自己负责的事项。本原型为单文件静态页面，覆盖产品全部界面与关键交互。

S1事项跟踪（管理员视角）

  • 左侧任务夹文件树（文件夹可嵌套）
  • 右侧「任务管理」：任务增删改查、小任务（仅一层）、双击打开编辑浮窗
  • 右侧「情况看板」：成员筛选、完成度统计卡片、点击卡片展开预计完成时间柱状图与分页任务列表
  • 默认查询昨天至今：进度变化 + 进展详情 code-diff 对比，可自定义日期重新查询

S2成员管理

  • 团队成员列表：角色、负责/协作中任务数
  • 添加 / 编辑 / 移除成员
  • 按成员生成分享链接：复制 / 重置 / 吊销
  • 每个成员独立链接；任务数据全员可见，写权限按负责人区分

S3成员视图（分享链接落地页）

  • 通过局域网链接访问，展示与管理员相同的团队全部事项
  • 「我负责的」任务可更新进度与进展详情
  • 「我协作的」和「其他成员的任务」只读
  • 三组标题可点击折叠 / 展开，标题保留分组计数
  • 对比 A（陈晨）/ B（林悦）两个链接：数据相同，可编辑范围不同

产品形态与链接模型

本地 CLI 服务
ztask serve → Web UI（本机 & 局域网）
http://192.168.1.5:8123 → 本地数据文件
~/.ztask/data.json 管理员访问完整 Web UI；成员通过 /#/s/<token> 链接查看团队全部事项，仅自己负责的事项可编辑

关键交互清单（评审用）

  • 任务夹树：点击任务夹切换右侧内容；点击树中任务直接打开编辑浮窗；文件夹可折叠。
  • 任务行：单击打开编辑浮窗；点击进度条原地修改进度；悬停行尾出现「编辑 / 添加小任务 / 删除」。
  • 情况看板：成员 chips 多选（不选 = 整体）；点击统计卡片在下方展开该集合的预计完成时间分布柱状图与紧凑分页任务列表，再点一次收起；点击任务行打开任务详情浮窗。
  • 时间段查询：默认自动查询昨天 00:00:00 至当前时刻并列出变化任务；可修改起止日期重新查询（自定义结束日期包含至 23:59:59），查询结果默认全部展开，支持单个或批量展开 / 折叠左右并排的进展详情 diff（红 = 删除，绿 = 新增）。
  • 成员管理：行内生成 / 复制 / 重置 / 吊销分享链接（危险操作有确认弹窗）；「添加成员」弹窗。
  • 成员视图：展示团队全部事项；只有「我负责的」任务可改进度与追加进展，其他任务只读。进展详情为追加式（历史保留，供时间段 diff 对比）；被重置/吊销的链接进入「链接已失效」页（见顶部导航「失效链接」）。
