# Charter

[English](charter.en.md) | 中文

## 愿景

ZTask 是一个团队进度管理工具：让团队对一个目标「现在推进到哪、谁在管、下一步是什么」有一致答案。它服务的是进度可见性，不是流程管控。

## 边界

- 做：进度建模（目标、里程碑、事项状态）、进度呈现、多人协作下的状态一致性。
- 不做（初始阶段）：完整项目管理（甘特图、资源排期）、即时通讯、细粒度权限体系。
- 边界随阶段演进，收缩或扩张都改本文件，不留口头约定。

## 现状

项目处于初始阶段：产品形态未定，先行的工程工作是文档体系（双语、有预算、有门禁）与开发流程门禁（流程树尚未初始化，等待单独规划）。

## 演进

路线图待规划；规划落地时在 `.agents/flow/` 建流程树（规则见仓库内 flow README），并回到本文件校验新方向不越界。
