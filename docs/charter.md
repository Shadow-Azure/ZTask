# Charter

[English](charter.en.md) | 中文

## 愿景

ZTask 是一个团队进度管理工具：让团队对一个目标「现在推进到哪、谁在管、下一步是什么」有一致答案。它服务的是进度可见性，不是流程管控。

## 边界

- 做：进度建模（目标、里程碑、事项状态）、进度呈现、多人协作下的状态一致性。
- 不做（初始阶段）：完整项目管理（甘特图、资源排期）、即时通讯、细粒度权限体系。
- 边界随阶段演进，收缩或扩张都改本文件，不留口头约定。

## 现状

项目已建立可运行的 CLI、服务端、管理端外壳、共享契约与存储恢复基座；进度建模和任务工作流按 M3 及后续 milestone 推进。文档体系与开发流程门禁已初始化并随实现同步维护。

## 演进

路线图与当前 milestone 见 [.agents/flow/roadmap.md](../.agents/flow/roadmap.md)。扩大产品边界前先改本文件，再调整流程树中的交付单元。
