# 事故复盘

[English](README.en.md) | 中文

复盘对象不限于线上事故：门禁误放行、流程被绕过、双语配对长期漂移，都值得复盘。

## 流程

1. 事故发生后新建 `docs/postmortem/yyyy-mm-dd-主题.md`（中英三件套，同常驻文档规则）。
2. 正文按「时间线 → 影响 → 根因 → 行动项」组织；行动项须可验证。
3. 事故件是冻结历史：进库后不修改，后续进展写新文件并互链。事故件不进 [docs 索引](../README.md)，按编号浏览。

## 门禁

事故件同样受词数预算以外的全部文档门禁约束（配对、行宽、死链）；发现门禁本身是根因时，行动项里必须包含门禁修复及其自测试。
