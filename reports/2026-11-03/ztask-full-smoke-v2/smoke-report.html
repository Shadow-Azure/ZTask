P1

新建任务时小任务被静默丢弃

首轮现象
新建浮窗可录入小任务，但 POST body 不含小任务，保存后显示 0 个。
期望
主任务和小任务草稿在创建时一起持久化。
根因
create mutation 只发送主任务字段；POST 服务端没有创建小任务意图。
Fixed · API + 组件看护 + v2 回归通过
P1

删除成功后确认弹层残留

首轮现象
任务已从树和列表消失，但确认层仍覆盖页面。
期望
删除成功后确认层与编辑器一起关闭。
根因
delete mutation success 只关闭外层编辑意图，未复位内层确认状态。
Fixed · 组件看护 + v2 回归通过
P1

关闭后重开 LAN 使用错误端口

首轮现象
服务实际运行 18131，重开 LAN 仍默认提交旧端口，成员基址不可达。
期望
重新开启时默认端口应回到 loopback 实际端口。
根因
关闭操作未同步 LAN 表单端口，旧 shareBaseUrl 残留。
Fixed · GUI/组件看护 + v2 回归通过
