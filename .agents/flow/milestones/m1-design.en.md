The design stage before any ZTask implementation: align the HTML prototype screen by screen with the user in the web client first, then write the full-stack design documents against the prototype; only after the documents are reviewed and agreed do we plan the later milestones, roadmap items, and issues.

- This stage produces only the prototype and design documents; no front-end or back-end implementation code lands here.
