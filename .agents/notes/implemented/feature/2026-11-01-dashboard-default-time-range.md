# Agent Note: 情况看板默认时间范围与边界

Status: implemented

[English](2026-11-01-dashboard-default-time-range.en.md) | 中文

## Problem

[m1-01 原型](../../../../plan/m1-01-ui-prototype/ztask-prototype.html)的情况看板使用固定历史日期，进入页面后必须手动点击查询才有结果。原有日期框和字符串比较没有定义真实时间戳，无法区分默认“昨天至今”的结束时刻与自定义结束日期的边界。

## Decision

情况看板默认自动查询本地时区昨天 00:00:00.000 至当前精确时刻，进入页面直接展示变化任务，并提供“更新至现在”。修改任一日期后切换为自定义模式，点击查询时起点取开始日期 00:00:00.000，终点取结束日期 23:59:59.999，以包含两个完整自然日。筛选区增加“昨天至今”状态、起止日期标签和边界说明；结果区显示实际查询时间戳和变化数量。原型历史数据按当前时间相对生成，保证默认范围有可验收的变化；历史快照比较改为真实时间戳，位于边界的快照包含在结果中。

## Alternatives considered

未把默认终点设为今天 23:59:59.999，因为这会纳入当前时刻之后的数据；未把自定义终点设为当天 00:00:00，因为这会漏掉结束日期几乎全天的进展；未采用 00:00:01 作为起点，因为会漏掉恰好午夜的数据。未引入双月日历弹窗，保留现有 inline 查询结构，只用快捷范围与状态摘要降低操作成本。

## Consequences

默认查询与自定义日期查询具有不同且明确的结束边界，界面会展示本次实际使用的区间。原型测试覆盖默认昨天至今、自定义整天边界、禁止未来结束时刻、无效区间和快照边界包含；浏览器截图验收覆盖自动结果和默认筛选布局。
