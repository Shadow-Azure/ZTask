# Agent Note: 任务树状态计数与只读进度

Status: implemented

[English](2026-11-01-tracker-tree-progress.en.md) | 中文

## Problem

[m1-01 原型](../../../../plan/m1-01-ui-prototype/ztask-prototype.html)的任务夹仅显示任务总数，无法判断剩余工作量；任务节点也需要直接展示进度，且固定宽度左栏不能兼顾长任务名和右侧任务板。

## Decision

任务夹右侧用绿色勾选与已完成数、红色圆圈与未完成数表示递归任务统计，只有进度恰好为 100% 才计入已完成。任务节点右端使用 18px SVG 圆形进度环和百分比，环形轨道始终可见，进行中为蓝色、100% 为绿色；圆环带有 `progressbar` 语义和当前值。不在树内引入编辑控件，右侧快捷改进度后同步刷新任务树。左右栏之间使用带扩大热区的分隔条，支持指针拖拽和左右方向键，宽度限制在 220–480px，并至少为任务板保留 480px。

## Alternatives considered

未采用悬停后才显示进度，因为进度应可持续扫读；未采用横向线形进度条，因为任务名、文件夹状态和进度同时出现时视觉噪声更大，圆形进度环在密集树节点中占用宽度更少；未采用树内滑块，因为用户只需查看进度，额外编辑入口会增加误触与视觉噪声；未采用仅 1px 的分栏线热区，因为难以命中。

## Consequences

任务树默认宽度从 264px 调整为 340px，以同时容纳名称和进度。18px 圆环加百分比把进度区域宽度从 76px 压缩到 49px，为长任务名留出更多空间。完成状态与进度来源仍统一使用任务数据，不新增独立的树状态。
